# NovaOS - mises à jour

> [!WARNING]
> **Attention : NovaOS est en développement.** NovaOS est en cours de développement : c'est un système d'exploitation écrit de zéro par un passionné, pas un produit fini. Des bugs sont possibles. Garde une copie de tes fichiers importants, et ne l'installe pas sur un PC dont tu as absolument besoin.

Dernière version : **NovaOS 1.5** (publiée le 24/11/2026).

Nouveautés : Correction du demarrage (ligne A20) : NovaOS demarre maintenant dans VirtualBox et sur les PC concernes ; nouvelle commande iso

Ce dépôt sert aux mises à jour automatiques de NovaOS (site : GitHub Pages). Les PC NovaOS y cherchent les nouvelles versions et demandent toujours à leur utilisateur avant d'installer. Chaque version est signée (`novaos.maj`) ; les fichiers `noyau-N.bin` et `etape2-N.bin` sont vérifiés avant d'être installés.
